# Recorded sounds

Drop real kitchen recordings here and list them in `manifest.json`; the game uses them instead of the synthesized fallbacks. Several takes per sound, picked at random:

```json
{
  "crack": ["crack-1.mp3", "crack-2.mp3", "crack-3.mp3"],
  "plop": ["plop-1.mp3", "plop-2.mp3"],
  "tap": ["tap-1.mp3"],
  "clink": ["clink-1.mp3"]
}
```

Keep them short (under a second), trimmed to the moment of contact, and the whole folder under about 3 MB. CC0 sources such as freesound.org are fine, or record them with a phone in your own kitchen.
